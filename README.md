# Splattastic
Mobile Ink Studio playground. Drag to orbit, pinch to zoom, tap to interact, choose scenes, add gems and change materials. Uses upstream MIT Ink Studio engine with a simplified square-splat preview.

## Run locally
`npm install && npm run build`, then `npx serve dist`.

## Deploy
[Enable GitHub Pages](https://github.com/RStevens-dev/Splattastic/settings/pages) → Source → GitHub Actions. Run [Deploy mobile demo](https://github.com/RStevens-dev/Splattastic/actions/workflows/pages.yml). Physical-device testing pending.
