# Splattastic — Theme Park Lab
Mobile Ink Studio playground with original attractions: Thunder Trail coaster, Starlight Wheel and Fireworks Kingdom. Drag to orbit, pinch to zoom, tap rides to toggle speed, pause or reset, and switch attractions from the scene selector. The original sculpt lab and engine demos remain available. Uses upstream MIT Ink Studio engine with a simplified square-splat preview.

## Run locally
`npm install && npm run build`, then `npx serve dist`.

## Deploy
[Enable GitHub Pages](https://github.com/RStevens-dev/Splattastic/settings/pages) → Source → GitHub Actions. Run [Deploy mobile demo](https://github.com/RStevens-dev/Splattastic/actions/workflows/pages.yml). Physical-device testing pending.
